# 🧩 Projeto Sudoku - DIO

Este é um projeto desenvolvido como parte do desafio da **Digital Innovation One (DIO)**.  
O objetivo é criar um jogo de Sudoku em **Java**, utilizando **Swing** para interface gráfica.

---

## 📌 Descrição
O jogo implementa as principais regras do Sudoku:
- Tabuleiro 9x9.
- Preenchimento apenas de números válidos (1–9).
- Botões para verificar status, resetar e finalizar o jogo.
- Interface gráfica amigável utilizando **Java Swing**.

---

## 🛠️ Tecnologias Utilizadas
- Java (versão 17+ ou superior).
- Swing (interface gráfica).
- IntelliJ IDEA (recomendado para rodar o projeto).
